# Кино НЭН: «Что посмотреть с детьми»

Новая версия сервиса n-e-n.ru/kino/. Сделана заново вместо приложения из ветки `feature/watch-service` репозитория nen_app. Почему — в [AUDIT.md](AUDIT.md).

- Все страницы отдаются готовым HTML, и поисковики видят текст.
- У каждого фильма своя карточка редакции: о чём он, почему советуем, с какого возраста, что важно знать родителям и о чём поговорить после просмотра.
- Дизайн сделан по стайлгайду НЭН, как в книжном сервисе [n-e-n.ru/knigi](https://github.com/NancyKhacha/knigi).

**Рабочая версия:** https://nancykhacha.github.io/kino/. Она закрыта от индексации и пересобирается сама после каждого изменения в ветке `main`.

## Разработчику

Начать с [TZ.md](TZ.md): как собрать и поставить сервис на n-e-n.ru и что в нём есть.

```bash
NEN_PREVIEW=0 python3 site/build.py --out dist   # сборка для n-e-n.ru/kino/ (Python 3, без зависимостей)
python3 scripts/seo_check.py dist                # проверка перед выкладкой: «ошибок: 0»
python3 site/build.py                            # рабочая версия в docs/ (noindex)
```

Устройство репозитория:

| Папка | Что в ней |
|---|---|
| `site/build.py` | генератор сайта: шаблоны страниц, мета-теги, JSON-LD, sitemap |
| `site/assets/` | стили (`nen.css`), скрипт (`app.js`: фильтры, подбор, избранное, «Поделиться»), иллюстрации |
| `site/data/titles.json` | факты о фильмах: название, год, страна, длительность, маркировка |
| `site/frames/` | кадры: WebP для страниц и JPG для превью в соцсетях |
| `site/content/` | словари тем, подборки, вступления страниц, статьи журнала НЭН о фильмах |
| `cards/` | карточки редакции (`pilot.json`, `batches/*.json`), стайлгайд и задание для авторов |
| `fixes/` | исключённые фильмы и фильмы, которые ждут решения редакции |
| `scripts/` | проверки, сбор пометок для редакции, загрузка кадров |
| `.github/workflows/pages.yml` | автосборка рабочей версии на GitHub Pages |

## Редакции

- [cards/review.csv](cards/review.csv) — по строке на каждый фильм: опубликован или нет и почему, возраст, маркировка, исправленные факты, пометки авторов «сверить».
- [cards/PROGRESS.md](cards/PROGRESS.md) — сколько фильмов опубликовано, пропущено и ждёт решения.
- [fixes/hold.csv](fixes/hold.csv) — фильмы, которые ждут решения редакции. Пока они в этом списке, на сайт они не попадают.
- [fixes/removed.csv](fixes/removed.csv) — взрослые фильмы из старой базы, убранные сразу.
- [cards/STYLEGUIDE.md](cards/STYLEGUIDE.md) — как писать карточки.

Другие команды:

```bash
python3 scripts/check_cards.py cards/batches/batch-001.json   # проверить карточки
python3 scripts/collect_notes.py                              # обновить review.csv и PROGRESS.md
python3 scripts/fetch_frames.py                               # скачать недостающие кадры
```
